实现要点

高校库右键菜单
给 university-workspace 列表项增加 ContextMenu："补充缺失数据" / "重新全量抓取"。点击后关闭 Sheet，跳转到聊天区，自动填入带大学名的预置指令
侧边栏跳转按钮
任务与大学关联（通过 Task.status + summary API 中的 university 字段）。在任务项右侧加一个外链图标，点击打开高校库 Sheet 并 scrollTo + 高亮目标大学
大学识别
从任务标题或 Agent 结果中提取大学名称（已有 classify API），存到 Task 的 metadata 字段。侧边栏以此来关联跳转

高校库 Sheet 打开后，目标大学行短暂闪烁（amber/primary ring + scale），持续 2s 后恢复，引导视线定位
