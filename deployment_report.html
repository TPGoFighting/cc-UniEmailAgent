3 Docker 7 步部署

1

环境准备

安装 Docker Engine + Docker Compose Plugin

2

克隆代码

git clone <repo> && cd UniEmailAgent

3

配置环境变量

编辑 backend/.env，填入 DEEPSEEK_API_KEY、LANGCHAIN_API_KEY 等

4

构建镜像

docker compose build

5

启动服务

docker compose up -d

6

Nginx 反代 + SSL

配置 Certbot 自动申请 HTTPS 证书，绑定域名

7

验证

访问 https://your-domain.com 确认正常运行
