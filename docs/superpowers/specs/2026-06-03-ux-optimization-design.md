## 1. 流式反馈 — 结构化步骤卡片

### 问题
爬取任务运行时，用户只看到 TypingIndicator（三个跳动点），完全不知道 Agent 在做什么。数据分析任务则完全黑盒。

### 方案
后端通过 WebSocket 推送结构化进度事件，前端渲染为步骤卡片管线。

### WebSocket 新增消息类型

```json
// 学院阶段开始
{ "type": "stage_start", "stage": "college",
  "college": "计算机科学与技术系", "college_index": 1, "college_total": 5 }

// 子阶段进度更新
{ "type": "stage_progress", "stage": "college",
  "phase": "extracting",           // "listing" | "extracting" | "done"
  "found": 87, "extracted": 45, "total_pages": 87 }

// 学院阶段完成
{ "type": "stage_done", "stage": "college",
  "college": "计算机科学与技术系",
  "found": 87, "valid_email": 82, "elapsed_ms": 34120 }
```

### 前端渲染

3 种卡片状态，使用 Agent 气泡同款 `rounded-[24px] rounded-tl-md` 样式：

| 状态 | 图标 | 边框 | 背景 | 内容 |
|------|------|------|------|------|
| 已完成 | 绿色对勾 SVG | `rgba(0,0,0,0.06)` | `rgba(16,163,127,0.03)` | 学院名 + 阶段描述 + 邮箱数 + 耗时 |
| 进行中 | 黄色旋转 spinner | `rgba(234,179,8,0.2)` | `rgba(234,179,8,0.04)` | 同上 + 进度条（`#eab308`） |
| 等待中 | 序号数字 | `dashed rgba(0,0,0,0.06)` | `transparent` | 学院名 + "等待中..." |

### 改动范围
- **后端**: `main.py` — WebSocket 推送新的结构化事件类型；`claude_agent.py` — Agent 执行过程中 emit `stage_start/progress/done` 事件
- **前端**: 新增 `components/crawl-progress.tsx` — 步骤卡片组件；`chat-area.tsx` — 在消息列表底部渲染爬取进度（替代/补充 TypingIndicator）

## 2. 任务完成后数据感知 — 内联摘要卡片

### 问题
任务完成后只显示 6 个下载链接，用户需要下载文件才知道「到底抓了多少人、邮箱覆盖率多少」。

### 方案
任务完成后，在 Agent 消息下方自动插入数据摘要卡片。

### 卡片内容

- **4 个核心指标**（大字显示）：教师总数、有效邮箱数、覆盖率百分比、学院数
- **学院分解**：每个学院的采集数 + 覆盖率进度条
- **前 5 行预览**：姓名、学院、职称、邮箱 的紧凑表格
- **下载链接**：CSV 高亮显示，其余格式折叠为 "+N"
- 点击可展开完整数据表格

### 后端新增 API

```
GET /api/history/{task_id}/summary
```

返回：
```json
{
  "total_teachers": 87,
  "valid_emails": 82,
  "coverage": 0.943,
  "colleges": [
    { "name": "计算机科学与技术系", "total": 64, "with_email": 60 },
    { "name": "数学学院", "total": 23, "with_email": 22 }
  ],
  "preview_rows": [ /* 前 5 行数据 */ ],
  "files": [ { "filename": "...", "ext": "csv", "url": "..." } ]
}
```

### 改动范围
- **后端**: `main.py` — 新增 summary API，从已有 CSV 读取统计
- **前端**: 新增 `components/completion-card.tsx`；`chat-message.tsx` — 在 done 事件后渲染摘要卡片

## 3. 侧边栏任务管理

### 问题
所有任务外观一致，无状态区分，无筛选，无时间分组。

### 方案

#### 时间分组
纯前端逻辑，根据 `Task.date` 字段分组：
- 今天
- 昨天
- 本周
- 更早

#### 状态徽章
从 `Task.status` + summary API 获取：

| 状态 | 徽章 | 样式 |
|------|------|------|
| 运行中 | 加载动画图标 + "运行中" | amber 背景 |
| 已完成（有数据） | 对勾图标 + "87人" | green 背景 |
| 已完成（纯对话） | 对话图标 + "对话" | blue 背景 |
| 失败 | 叉号图标 + "失败" | red 背景 |

#### 快速筛选
顶部 pill 筛选栏：全部 / 运行中 / 有数据 / 失败（纯前端过滤）

#### 右键菜单
复用项目已有的 `dropdown-menu.tsx`：
- 重命名
- 置顶 / 取消置顶
- 导出数据
- 删除

### 改动范围
- **前端**: `sidebar.tsx` — 添加时间分组、筛选 pills、右键菜单
- **前端**: `sidebar-task-item.tsx` — 添加状态徽章、跳转图标

## 4. 跨面板联动

### 场景一：高校库 → 聊天

在高教库中，每行高校有一个可见的 `⋮` 操作按钮（点击或右键均可）：
- **补充缺失数据** → 关闭高校库 Sheet，跳转聊天区，输入框预填"补充南京大学教师邮箱数据，重点补充 [学院名]"
- **重新全量抓取** → 同上，输入框预填"重新抓取南京大学所有教师邮箱"
- **查看数据详情** → 展开该高校的数据表格

### 场景二：侧边栏 → 高校库

侧边栏任务项右侧常驻跳转按钮（外链图标），仅关联了大学数据的任务显示：
- 点击 → 打开高校库 Sheet，自动定位并高亮目标大学（2 秒框闪烁动画）
- 无关联数据的任务显示灰色文字"无关联数据"

### 可发现性设计

1. `⋮` 按钮和跳转图标始终可见，不依赖 hover 或右键
2. 高校库首次打开且有数据时，顶部显示引导条（可关闭）
3. 右键保留作为快捷键
4. 所有操作按钮 hover 时显示 tooltip（0.6s delay）
5. 跳转按钮仅在任务关联了高校数据时出现

### 改动范围
- **后端**: Task/History API 返回 metadata 字段（university 名称，从 classify API 结果中提取）
- **前端**: `university-workspace.tsx` — 添加 `⋮` 按钮 + 右键菜单 + 首次引导条
- **前端**: `sidebar-task-item.tsx` — 添加跳转图标
- **前端**: `chat-area.tsx` — 支持从外部预填输入框内容（通过 UIStore 新字段 `pendingInput`）
- **前端**: `stores/ui-store.ts` — 新增 `pendingInput`、`highlightUniversity` 字段

## 5. 交互细节打磨

### 5.1 连接状态提示

- WebSocket 断开时：聊天区顶部显示黄色横幅「连接断开，正在重连...」
- 重连成功：绿色提示「已连接」2 秒后淡出消失
- 不干扰消息列表滚动

### 5.2 消息操作撤销

- 删除/编辑消息后，底部弹出 Toast「已删除。撤销」（3 秒后自动消失）
- 点击「撤销」恢复消息
- 实现：保留被删除消息的引用在本地 state 中，超时后清除

### 5.3 桌面通知

- 爬取完成时：`Notification API` 发送「南京大学教师邮箱抓取完成 — 87 位教师，82 个有效邮箱」
- 爬取失败时：发送「任务失败 — [错误摘要]」
- 仅在用户已授权通知权限且浏览器标签页不可见时发送

### 改动范围
- **前端**: 新增 `components/connection-banner.tsx`
- **前端**: 新增 `components/undo-toast.tsx`
- **前端**: 新增 `hooks/use-notification.ts`
- **前端**: `use-task-stream.ts` — 监听 WS 状态变化
- **前端**: `chat-store.ts` — 添加撤销相关状态

## 6. 新手引导 — 功能引导 Tour

### 方案
首次打开页面时展示 3-4 步引导叠加层（使用 localStorage 记录是否已完成）：

1. 输入框聚焦高亮 + 提示：「在这里输入你的任务，比如抓取某大学的教师邮箱」
2. 侧边栏高亮 + 提示：「左侧管理你的历史任务，随时切换查看」
3. 顶部按钮栏高亮 + 提示：「高校库查看已有数据，邮件发送给教师」
4. 完成引导

### 交互
- 每步有「下一步」和「跳过」按钮
- 点击页面空白处不关闭（防误触）
- 引导完成后 localStorage 写入标记，不再重复出现

### 改动范围
- **前端**: 新增 `components/onboarding-tour.tsx`
- **前端**: `app/page.tsx` — 集成引导组件，判断 localStorage
