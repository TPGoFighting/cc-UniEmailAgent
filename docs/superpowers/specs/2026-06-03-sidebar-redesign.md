# 侧边栏任务项重设计

**日期**: 2026-06-03
**来源**: 用户反馈 — 侧边栏按钮遮挡、文字显示不全、排版不美观

## 目标

解决侧边栏任务项（`sidebar-task-item.tsx`）的三个核心问题：
1. **遮挡**：hover 操作按钮与文字内容重叠
2. **信息不完整**：任务标题被截断，无法看到完整内容
3. **美观性**：排版拥挤，视觉层次混乱

## 设计方案：混合模式

核心思路：**选中项展开为完整卡片，非选中项保持紧凑单行**。利用"选中"这个天然状态来区分信息密度。

### 两种状态

| 状态 | 外观 | 交互 |
|------|------|------|
| **折叠态**（非活跃任务） | 图标 + 单行截断标题 + 状态标签 | hover 仅改变背景色，点击选中后展开 |
| **展开态**（当前活跃任务） | 图标 + 完整标题（可换行）+ 元信息行 + 分隔线 + 底部操作栏 | 操作栏始终可见 |

### 展开态布局（从上到下）

```
┌────────────────────────────────────────┐
│ ✓  抓取南京大学计算机学院教师邮箱        │  ← 标题完整换行
│    06-03  ✓ 87人                       │  ← 元信息行（日期 + 状态标签）
│   ───────────────────────────────────  │  ← 分隔线
│          🌐 高校库  📌 置顶  ✏️ 重命名  🗑 │  ← 底部操作栏（右对齐，文字不换行）
└────────────────────────────────────────┘
```

### 折叠态布局

```
┌────────────────────────────────────────┐
│ ✓  抓取南京大学计算机学院教师...  ✓ 87人 │  ← 单行截断
└────────────────────────────────────────┘
```

### 状态图标

| 状态 | 图标 | 颜色 |
|------|------|------|
| 运行中 | `Loader2` 旋转动画 | 琥珀色 `#f59e0b` |
| 完成（有数据） | `CheckCircle2` | 翠绿色 `#10A37F` |
| 完成（纯对话） | `MessageSquare` | 靛蓝色 `#6366f1` |
| 失败/已停止 | `XCircle` | 红色 `#ef4444` |
| 置顶 | `Pin`（填充） | 主色 `#10A37F` |

### 状态标签（折叠态右侧 + 展开态元信息行）

- 运行中：琥珀色底 `运行中`
- 完成有数据：绿色底 `✓ N人`
- 完成纯对话：无标签
- 失败：红色底 `失败`
- 已停止：灰色底 `已停止`

## 操作栏按钮

展开态底部操作栏，右对齐，水平排列，**文字不换行**：

1. **高校库**（仅有关联大学时显示）：`Globe` 图标 + "高校库"
2. **置顶**：`Pin` 图标（置顶时填充）
3. **重命名**：`Pencil` 图标
4. **删除**：`Trash2` 图标（hover 红色高亮）

每个按钮独立可点击，`stopPropagation` 阻止触发任务选择。

## 置顶项

- 折叠态：图标替换为 `Pin`（填充）
- 展开态：底部操作栏中 `Pin` 按钮高亮
- 不受时间分组影响，始终显示在列表顶部

## 筛选与分组

- 筛选 pills（全部 / 运行中 / 有数据 / 失败）：**保持不变**
- 时间分组（今天 / 昨天 / 本周 / 更早）：**保持不变**
- 搜索栏：**保持不变**

## 实现要点

### `sidebar-task-item.tsx` 重构

1. 根据 `isActive` 切换折叠/展开渲染
2. 折叠态：单个 `<button>` 包裹图标 + 截断标题 + 状态标签
3. 展开态：外层 `<div>` 包含标题区 + 操作栏区，操作栏按钮用 `<button>` 防止嵌套问题
4. 展开态主点击区仍为 `<button>`，操作栏独立 `<button>` 处理 `stopPropagation`
5. 操作栏按钮使用 `whitespace-nowrap` 确保文字不换行

### 不做的事

- 不改动 `sidebar.tsx` 的整体结构
- 不增加右键菜单（保持简洁）
- 不影响其他组件

## 验证

- TypeScript 检查：`cd frontend && npx tsc --noEmit`
- 视觉检查：选中不同任务，观察展开/折叠切换流畅
- 边界情况：超长标题在折叠态正确截断、展开态正确换行
- 操作栏文字不换行
- 无 `<button>` 嵌套 hydration 错误
